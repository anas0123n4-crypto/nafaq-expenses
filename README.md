# نَفَق — دفتر مصروفات ذكي يتكلّم لغتك

تطبيق أندرويد فاخر (أندرويد 8.0+) لتسجيل المصروفات **بالصوت وبالعربية العامية**، مع بحث ذكي وإحصائيات، وبدعم كامل للذكاء الاصطناعي (Gemini و OpenRouter).

---

## ✨ المميزات

| الميزة | الوصف |
|---|---|
| 🎙️ تسجيل صوتي | اضغط الميكروفون وتكلّم: «اشتريت سدر كنافه بعشر دنانير» فيُسجّل الصنف والقسم والسعر تلقائياً |
| 🗂️ 16 قسم بألوان | طعام، خضار وفواكه، لحوم، حلويات، أكل جاهز، مشروبات، منظفات، أدوات منزلية، أثاث، ملابس، صحة، مواصلات، صيانة، ترفيه، تعليم، أخرى |
| 🔎 بحث ذكي | اختر نطاق تاريخ (من/إلى) + كلمة بحث + تصفية بالأقسام، واحصل على **الإجمالي لكل صنف** وكل بطاقة بالسعر والوقت |
| 🤖 ذكاء اصطناعي | أضف مفتاح Gemini أو OpenRouter من الإعدادات فقط، ثم اضغط «جلب النماذج» — يكفي المفتاح ولا شيء غيره |
| 📴 يعمل بدون إنترنت | قاموس عربي مدمج (572 كلمة من لهجات شامية/مصرية/خليجية/عراقية) يعمل بالكامل أوفلاين |
| 🎨 ثيم فخم | عاجي دافئ + ذهبي، بلا تدرجات لونية، بخط Cairo العربي |
| 📤 تصدير CSV | كل مصروفاتك في ملف واحد |

## 🔤 كيف يفهم التطبيق كلامك؟

1. **تطبيع النص**: توحيد الهمزات والألف المقصورة والتاء المربوطة، حذف التشكيل، وتحويل الأرقام العربية `٠١٢` إلى `012`.
2. **استخراج السعر**: understands أرقام وكلمات (`عشر دنانير` → 10، `بعشر` → 10، `دينارين` → 2، `15.5 دينار` → 15.5) ويتجاهل الكميات (`3 كيلو لحم بـ 20 دينار` → 20).
3. **تحديد الصنف**: إزالة أفعال الشراء والجمل الزائدة (`اشتريت من السوق شاورما دجاج` → `شاورما دجاج`).
4. **مطابقة القسم**: بحث في القاموس، ومعه مطابقة تقريبية (Levenshtein) تصحّح الأخطاء الإملائية.
5. **الذكاء الاصطناعي**: إذا لم يُتعرَّف على الصنف، يرسل النص للموديل المختار ويعيد الصنف والقسم.
6. **اختيار القسم يدوياً**: إذا فشل كل ذلك، تظهر لك شبكة أقسام ملوّنة للاختيار بنقرة واحدة.

## 🧪 البناء والنشر

المشروع يُبنى تلقائياً عبر GitHub Actions:

- كل push على `main` → تشغيل الاختبارات + بناء APK
- الملف جاهز للتحميل من صفحة الـ Run → Artifact باسم `nafaq-app-debug`
- عند إنشاء تاج `v1.0.0` يُنشر الـ APK في صفحة Releases تلقائياً

## 🔑 الخصوصية

- مفتاح الذكاء الاصطناعي يُخزَّن داخل التطبيق فقط (`SharedPreferences` خاص) ولا يُرسل لأي خادم غير مزوّد الذكاء الاصطناعي الذي تختاره.
- التطبيق لا يجمع أي بيانات شخصية ولا يحتوي على إعلانات.
